# 🤖 ChatGPT Clone (React + OpenAI API)

	Built an interactive AI chatbot application using React.js integrated with OpenAI API. The project enables real-time conversational responses with a clean and responsive user interface.
	Focused on efficient state management, API handling, and smooth user experience. Implemented dynamic chat rendering and optimized frontend performance for faster response handling.
	This project highlights skills in frontend development, API integration, and building AI-powered web applications.

	An AI-powered chatbot application built using React.js and OpenAI API that delivers real-time conversational responses with a clean and responsive UI.
